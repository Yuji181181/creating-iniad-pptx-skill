# output（生成物の出力先）

スライドを生成すると、デッキごとに `output/<デッキ名>/` が作られ、次のファイルが入る（場所は固定）。

| ファイル | 内容 |
|---|---|
| `spec.md` | 生成前に承認を得た仕様書（1 ページずつの詳細） |
| `build.py` | 仕様書どおりにスライドを作る生成スクリプト（`.venv/bin/python output/<デッキ名>/build.py` で再生成できる） |
| `<デッキ名>.pptx` | 完成したスライド |
| `shots/` | スクリーンショット（撮った場合のみ） |
| その他 | スクリーンショット用のコード（`*_demo.py` など）があれば同じフォルダに置く |

- デッキ名は英小文字とアンダースコア（例: `dijkstra`, `binary_search_tree`）
- このフォルダの中身は Git の管理対象外（講義資料や引用した画像が誤って公開されないように）。README だけ管理する
