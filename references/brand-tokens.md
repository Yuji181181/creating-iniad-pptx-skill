# INIAD ブランドトークン（実測値）

> 出典: INIAD 情報連携学部の講義資料。PDF は **全ページが画像化**されておりテキスト・フォント情報を持たないため、1267×713px にラスタライズした画像から色・位置を実測した。ロゴはユーザー提供の公式ロゴ画像の余白を切り詰め、白背景を透過した `assets/iniad-logo.png` を使用（`scripts/prepare_logo.py` で作成）。
> テンプレ `assets/iniad-template.pptx` はこの値から `scripts/build_template.py` で生成しており、値を変えるときは両方を同期させる。

## スライド
- アスペクト比: 16:9
- サイズ(EMU): cx=12192000 / cy=6858000（13.333 × 7.5 in）
- 背景: #FFFFFF（白のみ。色面背景は使わない）

## 配色
| 役割 | HEX | 用途 |
|---|---|---|
| ライン水色 | #5FB7E3 | 上下の水平ライン・両端ドット・中扉の中央ライン |
| ロゴ青 | #1DACE4 | 公式ロゴ内の青（ロゴ画像以外には原則使わない） |
| ヘッダ文字 | #31859C | 右上「情報連携学部」 |
| 本文・タイトル | #000000 | 標準文字色 |
| 箇条 第1階層 ● | #C00000 | 暗赤の丸 |
| 箇条 第2階層 ■ | #FF9900 | オレンジの四角。課題の設問番号（1. 2. 3.）も同色 |
| 強調（赤字） | #FF0000 | 重要語・「これが大事」系の注記 |
| 英語（日英併記） | #0033CC | 日英併記の英語行・英語タイトル、講義表紙の担当者名・連絡先 |
| 注釈（青字） | #0070C0 | コードの補足説明・ポイント解説・リンク的な注記 |
| フッタ | #BFBFBF | Copyright 表記・ページ番号 |
| 表ヘッダ | #404040 | 表の見出し行（白字・太字）。本文行は #FFFFFF と #F2F2F2 の縞 |
| コード注目箇所 | #C00000 | コード枠内で注目させたい識別子・行 |
| 実行結果枠の地 | #F2F2F2 | 出力を示す枠（コード枠は白地） |
| コード枠線 | #7F7F7F | コード枠・「次ページに解答がある」枠（0.75pt） |
| 図のプレースホルダ地 | #F2F2F2 | 画像が無いときの仮置き |

> 図中で 2 クラスを区別する場合は、元資料に合わせ「クラスA = 赤 #FF0000（○）、クラスB = 青 #0070C0（△）」を使う。

## フォント
| 用途 | 日本語(ea) / 英数(latin) | サイズ |
|---|---|---|
| タイトル（通常スライド） | Meiryo UI | 40pt・黒・外側の影（下方向、透明度 57%） |
| タイトル（中扉） | Meiryo UI | 54pt・中央揃え |
| 本文 lvl0 / lvl1 / lvl2 / lvl3 | Meiryo UI | 28 / 24 / 20 / 18pt（情報量が多い回は lvl1 を 18pt 程度まで下げる） |
| コード・実行結果 | Consolas | 18pt（長いコードは 16pt） |
| 枠のラベル（「コード」「実行結果」） | Meiryo UI | 16pt 太字 #595959 |
| 数式 | Cambria Math | 22pt 前後 |
| ヘッダ「情報連携学部」 | Meiryo UI | 16pt |
| フッタ | Arial Bold | 10pt |

> macOS には Meiryo UI / Consolas が無いため、LibreOffice のプレビューでは代替フォント（等幅っぽい見た目）になる。PowerPoint（Windows / Office 同梱フォント）では正しく表示される。プレビューの字形差はバグではない。
